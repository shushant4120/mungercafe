# Munger Cafe — product image correction

This update replaces the menu card images with local, item-matched image files. Local assets are included so the product images do not depend on a third-party image host. Some photos are AI-generated illustrative food photography, not photos of the cafe’s actual servings. Replace them with real dish photos before launch for best accuracy.

## Publish on GitHub Pages
1. Extract this ZIP.
2. Upload `index.html` and the entire `assets` folder to the root of `shushant4120/mungercafe`.
3. Allow `index.html` to replace the existing file, and ensure the `assets` folder is uploaded with all `.webp` images.
4. Commit the changes and wait for GitHub Pages deployment.
5. Visit https://shushant4120.github.io/mungercafe and hard-refresh with Ctrl+F5.

Do not upload `index.html` without the `assets` folder; product images use relative paths such as `assets/litti-chokha.webp`.
